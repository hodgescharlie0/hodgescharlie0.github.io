NPL Pool Valuation Model

Built

A working Excel model that prices a non-performing residential loan pool by splitting expected outcomes into cured and liquidated segments, applying distress-sale haircuts and disposition costs to the liquidated portion, and discounting both back to present value against the seller's asking price.

Excel NPL Pricing DCF Whole Loans
Property Value = UPB ÷ LTV
Cured Recovery = UPB × Recovery % (borrower resumes paying)
Liquidated Recovery = (Property Value × (1 − Haircut)) − (Property Value × Disposition Cost %)
Present Value = (Cured + Liquidated) ÷ (1 + Discount Rate)^Years
Decision = Present Value vs. Purchase Price

LBO Model — Leveraged Buyout Returns

Built

A five-year leveraged buyout model on a hypothetical software company — $150M entry EBITDA at an 8.0x entry multiple, financed at 5.5x leverage. The model builds a full debt paydown schedule (EBITDA growing 6% annually, with 40% of EBITDA converted to free cash flow used to pay down debt each year), then values the exit at the same 8.0x multiple to compute sponsor returns. The result — a 2.74x MOIC and roughly a 22% IRR — lands squarely in the range real private equity sponsors target, which is a good sanity check that the mechanics are sound, not just internally consistent.

LBO Debt Schedule IRR / MOIC Returns Analysis
Entry EV = Entry EBITDA × Entry Multiple | Entry Debt = Entry EBITDA × Leverage
Entry Sponsor Equity = Entry EV − Entry Debt
Each Year: EBITDA compounds at growth rate → FCF = EBITDA × Conversion %
Ending Debt = Beginning Debt − FCF (carries forward as next year's Beginning Debt)
Exit EV = Year 5 EBITDA × Exit Multiple | Exit Equity = Exit EV − Year 5 Ending Debt
MOIC = Exit Equity ÷ Entry Equity | IRR = MOIC^(1/Years) − 1

Returns are more sensitive to the exit multiple than to the growth assumption — moving exit from 6.0x to 10.0x (at 6% growth) swings IRR by ~19 points, versus ~14 points from the full growth range at a fixed 6.0x exit. Apple Inc. (AAPL) — DCF Valuation

Built

A five-year discounted cash flow model built on Apple's FY2025 financials — revenue growth decelerating from 7.0% to 4.5%, FCF margin expanding from 24.0% to 25.0% as Services mix grows, and a WACC derived from CAPM blended with Apple's actual capital structure. The model implies a fair value well below the current trading price, which is a genuinely useful result in itself — it shows where the market's assumptions (AI-driven growth, continued buybacks reducing share count, multiple expansion) diverge from a conservative, organic-growth-only DCF, rather than forcing the model to match the stock price.

DCF WACC / CAPM Terminal Value Equity Valuation
WACC = (Wₑ × Cost of Equity) + (W_d × After-Tax Cost of Debt)
Cost of Equity = Risk-Free Rate + Beta × Equity Risk Premium
FCF = Revenue × FCF Margin, projected FY26–FY30
Terminal Value = Terminal FCF × (1 + g) ÷ (WACC − g)
Equity Value = ΣPV(FCF) + PV(Terminal Value) − Net Debt
Implied Share Price = Equity Value ÷ Shares Outstanding
