NPL Pool Valuation Model

Built

A working Excel model that prices a non-performing residential loan pool by splitting expected outcomes into cured and liquidated segments, applying distress-sale haircuts and disposition costs to the liquidated portion, and discounting both back to present value against the seller's asking price.

Excel NPL Pricing DCF Whole Loans
Property Value = UPB ÷ LTV
Cured Recovery = UPB × Recovery % (borrower resumes paying)
Liquidated Recovery = (Property Value × (1 − Haircut)) − (Property Value × Disposition Cost %)
Present Value = (Cured + Liquidated) ÷ (1 + Discount Rate)^Years
Decision = Present Value vs. Purchase Price

LBO Model — Leveraged Buyout Returns

Built

A five-year leveraged buyout model on a hypothetical software company — $150M entry EBITDA at an 8.0x entry multiple, financed at 5.5x leverage. Builds a full debt paydown schedule and exit valuation to compute sponsor returns.

LBO Debt Schedule IRR / MOIC Returns Analysis
Entry EV = Entry EBITDA × Entry Multiple | Entry Debt = Entry EBITDA × Leverage
Entry Sponsor Equity = Entry EV − Entry Debt
Each Year: EBITDA compounds at growth rate → FCF = EBITDA × Conversion %
Ending Debt = Beginning Debt − FCF (carries forward as next year's Beginning Debt)
Exit EV = Year 5 EBITDA × Exit Multiple | Exit Equity = Exit EV − Year 5 Ending Debt
MOIC = Exit Equity ÷ Entry Equity | IRR = MOIC^(1/Years) − 1

Base case: 2.74x MOIC, ~22% IRR.

Apple Inc. (AAPL) — DCF Valuation

Built

A five-year discounted cash flow model built on Apple's FY2025 financials — revenue growth decelerating from 7.0% to 4.5%, FCF margin expanding from 24.0% to 25.0% as Services mix grows, and a WACC derived from CAPM blended with Apple's actual capital structure. Implies a fair value of $124.61 against a $336.13 market price — the gap reflects growth and buyback assumptions this conservative model doesn't capture.

DCF WACC / CAPM Terminal Value Equity Valuation
WACC = (Wₑ × Cost of Equity) + (W_d × After-Tax Cost of Debt)
Cost of Equity = Risk-Free Rate + Beta × Equity Risk Premium
FCF = Revenue × FCF Margin, projected FY26–FY30
Terminal Value = Terminal FCF × (1 + g) ÷ (WACC − g)
Equity Value = ΣPV(FCF) + PV(Terminal Value) − Net Debt
Implied Share Price = Equity Value ÷ Shares Outstanding
